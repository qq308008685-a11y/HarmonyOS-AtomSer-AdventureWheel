# 冒险大转盘案例导入说明

本文件说明 `cases/` 发布包的用途和导入前置条件。源码仓库为 [HarmonyOS-APP-adventure-wheel](https://gitcode.com/harmony-practice-center/HarmonyOS-APP-adventure-wheel)，案例信息已填写该真实地址。源码提交与文件校验不代表平台导入或应用市场上架完成。

## 发布物入口

- [发布物预览](./发布物预览.html)：集中查看封面、卡片、分享图、手机效果与架构图。
- [案例信息](../cases/case.json)：10 个模块，包含基础信息、介绍、条件、知识、实践、架构、预览、问题、迁移方向与拓展挑战。
- [实践教程](../cases/practice.html)：8 步目标、操作与完成标志，以及排障和安全说明。
- [README](../README.md)：工程运行与学习入口。

五类图片为封面 `cover.png`、卡片 `card.png`、分享 `share.png`、架构 `arch-diagram.svg`、手机全流程 `preview-phone.png`。按容器比例生成，不能用竖版原截图直接替换横版预览图。发布包不包含可选演示视频，本次未新录设备演示。

## 导入流程与验收

1. 使用上述公开仓库地址；`cases/case.json` 的 `baseInfo.repoUrl` 与 README 获取、反馈入口保持一致。
2. 将经检查的源码与 `cases/` 提交到仓库默认分支；不要上传签名材料、私人任务文件或构建产物。
3. 推送后确认无需登录即可读取默认分支中的 `cases/case.json`、`practice.html` 及引用图片。仅有一个可访问的空仓库并不足以导入案例。
4. 在平台执行“从公仓导入”。字段与媒体读取规则以平台当前实现为准。
5. 核对导入后的标题、卡片图、封面、六个知识点、实践教程、架构与手机预览，确认没有裁切或丢失。

2026-10-01 已确认仓库页面可匿名访问，并补齐原先缺失的仓库地址。文件校验与远程文件可读取不代替平台导入验收；目前尚未执行平台实际导入。

## 本地复核

本发布包使用以下生成器版本：

- [harmony-case-generator](https://gitcode.com/harmony-practice-center/huaweicloud-skills-practice/tree/main/skills/harmony-case-generator)
- 来源提交：`ad4c89066c6d653abc09ccac1441bc579288c43b`
- 公仓规范：v1.1，配套技能包含 2026-09-28 封面及卡片规则。

在可用 Python 环境中运行该生成器原版 `scripts/validate_case.py`，参数为工程的 `cases/` 目录。补齐真实仓库地址后，预期 V-1 至 V-10 均通过；不能通过修改校验器或虚构 URL 消除错误。

补充人工或专项检查：卡片为 1920×974，SVG 根尺寸为 2080×820，图标名在允许列表内，知识点使用 HTML 引言与要点列表，关键词使用 ` / ` 分隔，HTML 无脚本及本机路径，所有图片格式、尺寸和体积符合要求。

工程提供 `tools/check-case-package.mjs` 完成这些专项检查；预期返回 `LOCAL_PASS`、`errors: []`、`blockers: []`。这是本地文件校验通过，不表示已完成平台实际导入、设备验收或正式上架。

修改后重新暂存，再运行公开范围扫描和 Git 空白检查：

```powershell
node .\tools\check-case-package.mjs
node .\tools\check-public-source.mjs
git diff --cached --check
```
