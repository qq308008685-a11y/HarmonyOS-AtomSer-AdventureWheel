## 当前内容基线

标题为“冒险大转盘：用 AI 构建鸿蒙元服务”，入门难度，预计快速体验约 30 分钟，不含环境准备。README 的完整实践估计 2–4 小时；两者均为学习编排估计，不是运行测量。

首屏封面为 2080×960，与 README 首图共用；五类发布媒体采用樱桃可乐配色，合成引用 2026-10-02、API 24 手机模拟器的真实系统原图；原始截图与发布图片未将排版修订当作新的设备运行。README 正文保留三张关键实拍；教程通过统一教学素材表提供五张原始截图的固定版本下载。

实践内容与 README 保持一致：

- **方式 A · 云端工作区**：覆盖案例详情页（`云端实践` -> `体验版` / `持久化版` -> `立即进入` -> `创建`）与作业中心（`立即体验` -> `项目管理` -> `新建项目` -> `技术模板 = 空项目` -> `案例公仓地址`）两条入口，并在创建后引导通过**码道 CLI**读取 `README.md`、`build-profile.json5` 与 `entry` 模块完成工程上下文同步。
- **方式 B · 本地开发**：明确采用 **码道 IDE（推荐）+ DevEco Studio**（由码道 IDE 调用构建与模拟器，无需手动在 DevEco Studio 打开工程，真机调试时按需在 `File -> Project Structure -> Signing Configs` 配置签名），并强调 Windows 下工程目录路径**必须**为纯英文、无空格。
- **完整实践**：保留八步空项目 AI 实践、全部可复制提示词、勘误规则与完成标志。
