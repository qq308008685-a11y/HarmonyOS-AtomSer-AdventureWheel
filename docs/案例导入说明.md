本地模拟器通常无需签名配置；真机需开发者调试签名，云端设备按平台要求。登录、隐私同意、签名授权由本人决定，不让 AI 代为确认。

5. 若准备提交，暂存明确的公开文件后运行 `node .\tools\check-public-source.mjs` 和 `git diff --cached --check`。扫描对象是 Git 索引，不是未暂存的工作目录；10 月 15 日使用临时索引检查，正式提交前需再检查实际暂存区。

## 导入与发布验收

1. 经维护者确认后，将当前源码与 `cases/` 提交、推送到上述仓库。
2. 无登录凭据读取默认分支的 JSON、教程和全部引用媒体，比较实际字节；不能只凭网页返回 HTTP 200 判断原文件可读。
3. 在平台执行“从公仓导入”或其支持的 ZIP 导入方式，具体入口以平台实际实现为准。
4. 核对标题、学习时长、卡片、封面、知识点、八步教程、全部提示词、迁移附录、架构和手机预览。检查富文本清洗后的样式、远程原图、链接和锚点，不把本地浏览器结果当作平台验收。
