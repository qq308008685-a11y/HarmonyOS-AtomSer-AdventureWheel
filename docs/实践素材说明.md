# 冒险大转盘实践素材说明

素材版本：v1.0；日期：2026-10-02。

这些素材供 README 的“完整实践”使用：只取得数据、字段说明和视觉参考，让 AI 从空项目创建应用代码。快速体验则直接取得完整工程，两条路线不要混用。

## 内置任务数据

[内置任务-v1.0.json](../data/内置任务-v1.0.json) 是当前成品内置内容的独立数据副本，UTF-8、无 BOM。共 190 条：95 条真心话、95 条大冒险。保留原始稳定 ID、正文、程度和标签，不包含本地用户记录。

| 字段 | 类型/取值 | 含义 |
| --- | --- | --- |
| `format` | `adventure-wheel-built-in-reference` | 教学内置数据标识 |
| `version` | 字符串 `1.0` | 本套教学数据版本 |
| `language` | `zh-CN` | 简体中文 |
| `tasks` | 数组 | 任务列表 |
| `tasks[].id` | 唯一字符串 | 稳定关联标识，不因排序改变 |
| `tasks[].type` | `truth` / `dare` | 真心话 / 大冒险 |
| `tasks[].level` | `light` / `medium` / `deep` | 轻松 / 适中 / 深入，按此顺序分级 |
| `tasks[].text` | 非空字符串 | 展示在确认清单和结果卡片的完整正文 |
| `tasks[].tags` | 字符串数组 | 任务标签，可供分类扩展 |

内置任务只读。最高挑战程度筛选包含所选程度及以下的条目。开局数量为 2–20；启用且匹配的自定义任务最多占 `floor(数量 × 0.5)`。

该文件不是用户备份，不能直接在元服务“导入任务”中导入。自定义文件使用 `format: adventure-wheel-tasks`、数字 `version: 1`，字段与校验见[任务文件格式](./任务文件格式.md)。不要混淆两种格式和版本类型。

## 视觉与文案

配色为樱桃可乐：深樱桃 `#241117`、奶油底 `#FFF3DE`、内容面 `#FFF9ED`、樱桃红 `#B8324B`、蓝绿 `#3F7681`、黄色 `#F0C95A`。大冒险和真心话使用不同色系，完成状态使用灰色并加“完成”文字。

界面只保留易懂的操作词，例如“立即开始”“确认开局”“交给下一位”“任务库”。自定义正文最多 30 个 Unicode 码点，结果显示完整正文，扇区使用短标识。
